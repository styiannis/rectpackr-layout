There is no generated API reference, because the element has no methods, no
properties and no events to generate one from.
[Architecture and API](architecture-and-api.md) is the reference, and the
build emits `dist/custom-elements.json`, the machine-readable form of the same
three attributes. Live examples are in the
[CodePen collection](https://codepen.io/collection/dGpeLa).
